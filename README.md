# Victoria 3 · 驻军收益与成本

固定的 **卫戍营区** 在具体州雇用独立地方人员，消耗建设投入、政府工资、军需与基础设施，不产生可调动的野战营。

**状态：v0.3 实验实现，尚未在游戏中运行验证。目标 1.13 / 1.14 不是兼容性认证。**

## 已实现
- 三种生产方式：常备卫戍、军民服务、封存营区；每级950士兵、50军官岗位。
- 基础每级满员军需：轻武器5、粮食10、布料5、纸张2；军民服务额外粮食5、布料2、纸张2、服务5。
- 按实际就业/人口需求提供递减的动乱惩罚减免，上限40%；每级固定预留2基础设施，封存仍占用，拆除释放。
- 去激进资格至少20%覆盖、3次合格月检；军民服务资格至少50%覆盖、6次合格月检及整合/动乱/生活条件。
- 两套资格独立；不合格回退1次，连续2次停运/短缺/空员后清零；失控与换所有者重置。v0.2计时首次升级时作废。
- 月检只遍历有营区或残留服务记录的州，旧秩序修正移除后替换，避免累积。

## 当前启用范围与限制
**默认实际启用的是秩序效果、成本和资格记录。直接改变激进/忠诚人口尚未默认启用。**

- 去激进的库存限幅、剩余空间和负数调用已编写，但负数效果的人口转化语义尚未在游戏核实；`experimental_radical_effects_enabled=false`，仅用于后续开发测试。
- 忠诚目标算法、合格中立人口池限幅在Python模型中实现。当前已查接口仅证明州级忠诚效果，不能保证只作用于生活条件达标的中立人口，因此没有添加无差别州级忠诚调用。
- 建筑军需采用已核实的“是否短缺”布尔接口：任一输入短缺时停止收益。分级短缺仍待本地强度接口证明。
- 资格是**月度观察**，不宣称证明整月连续运行或完全杜绝月末切换套利。
- 与警察/法令的实际叠加待游戏测量，不宣称已实现乘算。
- 军民服务目前额外付费并记录资格，暂不直接增加忠诚；面向开发测试，尚不推荐作为完成版玩法使用。

## 开发与检查
Python 3.11+，无需第三方库：

```bash
python3 tools/generate.py
python3 tools/validate.py
python3 -m unittest discover -s tests -v
python3 scripts/package.py --target 1.13 --experimental
python3 scripts/package.py --target 1.14 --experimental
```

唯一数值源为 `balance.json`。生成文件需由生成器更新。脚本分支测试执行项目实际文本，但不验证游戏作用域、加载、人口语义或多人同步。未记录游戏验证前禁止正式包。
